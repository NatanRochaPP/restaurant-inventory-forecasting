# Forecasting-Driven Inventory Resupply for Restaurants using AI

Final-year dissertation project (**QHO656**, BSc (Hons) Computing, Southampton Solent University / QAHE).
A decision-support tool that forecasts item-level (SKU) demand for a restaurant and turns those
forecasts into cost-aware order recommendations, explicitly modelling UK bank-holiday, weather and
seasonality effects.

**Research question:** *Can an AI forecasting system that incorporates holiday/event calendars and
historical usage reduce stockouts and food waste versus current manual methods in a
quick-service/casual restaurant context?*

**Author:** Natan Rocha Paiva &nbsp;·&nbsp; **Supervisor:** Tendi Mhlanga

---

## Current status (AE1 progress point)

A reproducible baseline forecasting pipeline is complete and back-tested. It builds a 24-month
synthetic single-site dataset (14,620 rows, 20 SKUs) and compares four models with **rolling-origin
cross-validation** (12 folds, 7-day horizon) on sMAPE, MASE and WAPE.

| Model | sMAPE | MASE | WAPE |
|---|---|---|---|
| Naïve | 46.65 | 1.20 | 42.68 |
| Seasonal Naïve | 39.84 | 0.93 | 39.41 |
| ETS (Holt–Winters) | 34.22 | 0.71 | 31.02 |
| **Gradient Boosting** | **33.67** | **0.64** | **28.52** |

Gradient boosting reduces sMAPE by **15.5 %** versus Seasonal Naïve (MASE 0.64 < 1 also beats an
in-sample seasonal-naïve forecast). Exploratory analysis confirms strong weekly seasonality
(~50 % weekend uplift) and a ~26 % demand uplift on open bank holidays.

## Getting started

Requires **Python 3.12+**.

```bash
# 1. clone
git clone https://github.com/<your-username>/restaurant-inventory-forecasting.git
cd restaurant-inventory-forecasting

# 2. create and activate a virtual environment
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate

# 3. install dependencies
pip install -r requirements.txt

# 4. reproduce all data, figures and results
python baseline_forecasting.py
```

Everything is deterministic (fixed random seed `42`), so re-running regenerates identical data,
figures and metrics into `data/` and `outputs/`.

## Data

The dataset is **synthetic** and self-generated (no personal or guest data). Its effect sizes are
calibrated to magnitudes reported in the literature (e.g. weather sensitivity, holiday uplift) so it
behaves realistically for method development. It is fully regenerated by `baseline_forecasting.py`.
